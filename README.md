# 朱泽嘉个人作品集

基于 `React + TypeScript + Vite + Tailwind CSS` 搭建的个人作品集网站，内容聚焦大客户项目管理、商业产品设计、品牌活动运营与项目全流程交付案例。

## 本地开发

1. 安装依赖
   `npm install`
2. 启动开发环境
   `npm run dev`
3. 打包构建
   `npm run build`

## 项目结构

- `src/data/portfolioData.ts`：站点核心内容数据
- `src/components/`：页面模块组件
- `src/assets/`：本地静态资源

## 说明

当前项目用于个人展示与部署发布，不再保留默认模板说明。

## GitHub Pages 部署

1. 将项目推送到 GitHub 仓库的 `main` 分支
2. 进入 GitHub 仓库 `Settings -> Pages`
3. 在 `Build and deployment` 中选择 `Source: GitHub Actions`
4. 稍等 1-3 分钟，仓库中的 `Deploy GitHub Pages` 工作流会自动发布站点

发布成功后，公开网址通常为：

`https://你的 GitHub 用户名.github.io/仓库名/`
